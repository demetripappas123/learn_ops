# CertForge Studio – 3-Minute Demo Script

## Beat-by-Beat Flow (10 beats, ~18 seconds each)

---

### Beat 1: Open App
**Visual:** Load CertForge Studio homepage.  
**Narration:** "Welcome to CertForge Studio—the platform that turns real project work into structured, certification-aligned upskilling. Today, we'll walk through how a developer goes from project idea to certification readiness in minutes, not months."

---

### Beat 2: Enter Project Idea
**Visual:** Click "New Project" and type: *"Build a secure multi-tenant SaaS API with role-based access control using Azure."*  
**Narration:** "First, an engineer describes their actual project. No forms, no friction—just a simple description of what they're building."

---

### Beat 3: Project Intake Agent Output
**Visual:** Show AI analysis breakdown:
- **Skills needed:** Authentication, Azure Identity, Authorization patterns
- **Risk areas flagged:** "Ensure proper RBAC implementation"  
- **Related certifications:** AI-102, AZ-204, AZ-305

**Narration:** "Our AI Intake Agent instantly analyzes the project, identifies skill gaps, flags security risks, and maps it to relevant Azure certifications. All automatically."

---

### Beat 4: Learning Curator Maps to AI-102 and AZ-204
**Visual:** Show curated learning paths:
- **AI-102 alignment:** Module 2 (Entra ID integration), Module 5 (Managed identities)
- **AZ-204 alignment:** Section 3 (Identity & access), Hands-on labs

**Narration:** "The Learning Curator pulls together certified content—labs, docs, and exam-aligned resources—for both AI-102 and AZ-204, so the engineer learns what matters for their project *and* their certification goals."

---

### Beat 5: Planner Task Tree
**Visual:** Display interactive task breakdown:
- Phase 1: Entra ID integration (3 tasks)
- Phase 2: Managed identity setup (2 tasks)
- Phase 3: RBAC policies (4 tasks)
- Phase 4: Testing & validation (3 tasks)

**Narration:** "The Planner breaks the project into a structured task tree, with each task tied to learning outcomes and exam objectives. Engineers see exactly what to build, learn, and validate."

---

### Beat 6: Select "Secure Access with Entra ID and Managed Identity"
**Visual:** Click on Phase 1 task card. Expand to show:
- Objective, Success criteria, Linked exam topics, Starter code

**Narration:** "When the engineer selects a task—like 'Secure access with Entra ID and managed identity'—they get clear objectives, success criteria, and pre-configured starter code to get them moving immediately."

---

### Beat 7: Builder Coach Workflow
**Visual:** Show side-by-side:
- Left: Starter code template (Entra ID auth setup)
- Right: Coach suggestions, hints, and best practices
- Terminal output: Mock build run

**Narration:** "The Builder Coach guides them through the implementation with inline tips, debugging help, and links back to learning materials. They're building *and* learning in real time."

---

### Beat 8: Assessment Question
**Visual:** Show auto-generated assessment:
- **Question:** *"Your app uses managed identity. Why is this more secure than storing connection strings?"*
- **Choices:** A) Lower cost, B) Reduces credential exposure, C) Easier to deploy, D) Faster runtime
- **Feedback:** If wrong, links to relevant AI-102 module

**Narration:** "Adaptive assessments check understanding—not just code correctness. If they struggle, they're routed back to the right learning resources."

---

### Beat 9: Manager Dashboard
**Visual:** Show aggregate view:
- Team skills by certification (AI-102: 60% complete, AZ-204: 45%)
- Project completion rate, skill coverage, risk hotspots
- Individual progress: Engineer's Entra ID proficiency, learning velocity

**Narration:** "Managers see the big picture—team skill maturity, certification progress, and risk mitigation. They know which engineers are ready for what, and where to invest in upskilling."

---

### Beat 10: Close with Impact Statement
**Visual:** Fade to key metrics overlay:
- 60% faster skill validation vs. traditional training
- 3x higher exam pass rates
- Measurable role readiness

**Narration:** "CertForge Studio does not just help employees build. It turns execution into measurable, role-based upskilling. Every project becomes a certification milestone. Every task a learning moment."

**Final Visual:** CertForge Studio logo + tagline: *"Build Better. Certify Faster."*

---

## Timing Notes
- Each beat: ~18 seconds (narration + visuals)
- Total: ~3 minutes
- Pacing: Steady, conversational, no rushed clicks
- Optional: Add soft background music, transition fade effects
